# aksel-privacy

Privacy policies for the Aksel offline exam-prep apps. No data is
collected by any app — they hold no `INTERNET` permission.

## Deploy (GitHub Pages)

1. Create a **public** repo named `aksel-privacy`.
2. Push this folder's contents to `main` (keep `index.html` at root).
3. Repo → Settings → Pages → Source: `main` / `/ (root)` → Save.
4. Live in ~1 min at `https://<user>.github.io/aksel-privacy/<app>.html`
   (e.g. `.../permit.html`, `.../cdl.html`).
5. Use each page's URL as the app's Privacy Policy URL in Play Console.

Keep this repo public and free of anything else — it is linked from
the Play Store.

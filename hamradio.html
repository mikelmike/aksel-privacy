Privacy Policy — Aksel: Ham Radio Prep

Effective date: November 5, 2025

Aksel: Ham Radio Prep ("the app") is designed so that nothing you do inside it

can leave your device.

Data collection

None. The app does not collect, transmit, or share any personal

information. It does not create accounts, does not use analytics SDKs,

does not serve ads, and does not request the internet permission —

the Android operating system prevents it from making network requests

at all.

Data storage

All progress (practice stats, exam history, streaks, badges, bookmarks)

is stored locally on your device using Android SharedPreferences. It

is never uploaded anywhere. Using Settings → "Reset all progress" or

uninstalling the app erases all of it permanently.

Third parties

The app integrates no third-party services, SDKs, or trackers.

Permissions

The app requests no permissions beyond what a normal application

needs to draw on screen. Notably, it does NOT request:

  • Internet / network access
  • Location
  • Contacts, camera, microphone
  • Notifications

Changes

If this policy ever changes (for example, if an optional online feature

is added), this page will be updated before the change ships, and the

app will describe the change in its update notes.
